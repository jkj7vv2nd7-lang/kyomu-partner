# 教務パートナー v18 🏫

**日本の小・中・高校の先生のための、ブラウザだけで動く教務支援アプリ。**
観察記録・成績・通知表コメント・指導要録・保護者連絡・提出物・面談スケジュール・引き継ぎまで、
毎日の教務を「1つの画面」につなぎます。

> 🔐 **プライバシー第一設計**
> 児童生徒データは外部へ一切送信されません。すべてお使いのブラウザ内（localStorage）に保存されます。
> 「AI風」の文案生成も端末内のテンプレート処理です。外部CDN（表示用・フォント）のみ読み込みます。

## ✨ 特徴

- **インストール不要**：`index.html` を1ファイル開くだけで動作（単独HTML・約1ファイル完結）
- **22の機能画面**：授業案／観察記録（音声・カメラ・D&D）／通知表コメント（学期別保存）／指導要録／成績グラフ／IEP／時間割／保護者連絡文例／提出物／学級通信／名簿／出席簿（CSV）／係・掃除・席替え／日誌・週案／参観・懇談／**面談スケジュール表**／保健室・心の天気／ポートフォリオ（申し送りメモ）／学級の成長ストーリー／授業デザイン4.0／データ分析／設定
- **セキュリティ**：PINロック（ソルト付きハッシュ）／自動ロック／起動時ロック／AES-GCM暗号化バックアップ／復元ファイル自動サニタイズ／Brute-forceスロットル／全画面セルフテスト
- **教務の時短**：ランダム指名／今週の誕生日／今日の授業一覧／日誌下書き自動作成／全員出席ワンタッチ／係ローテーション／席替え手動入替／未処理バッジ／下書き自動保存（離脱時退避）
- **引き継ぎ支援**：児童別サマリーの「引き継ぎパックPDF」＋後任機で復元できる「引き継ぎJSON」
- **アクセシビリティ**：文字サイズ切替（Aa）／ダークモード（🌙）／Zen Maru Gothic
- **教師判断の尊重**：すべての提案・文案は「下書き・候補」。最終判断は常に先生に

## 🚀 使い方（3分）

1. `index.html` をダウンロード
2. ダブルクリックして **Chrome / Edge** で開く
3. 【⚙️ 設定】→ 基本情報とPINを保存 → 【🧑 児童生徒管理】で生徒を登録 → 利用開始
