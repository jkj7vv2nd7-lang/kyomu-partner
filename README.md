# 教務パートナー（Kyomu Partner）

学校の先生の日々の業務（授業準備・評価・保護者連絡・クラス運営など）を1つのアプリでまとめてサポートする、ブラウザだけで動くシングルファイルの教務支援アプリです。

インストール不要・サーバー不要。`index.html` を1つ開くだけで動作し、入力したデータはすべて**お使いのブラウザの中だけ**に保存されます（既定では外部には一切送信されません）。

---

## 📋 主な機能

- 🏠 ダッシュボード（朝・授業中・放課後・退勤前の業務をまとめて表示）
- 📖 授業案ジェネレーター／🧪 資料からAIで授業設計・スライド・インフォグラフィック・簡易動画を生成（任意機能）
- 📷 観察記録＋評価文案／📝 通知表コメント生成／📋 指導要録作成
- 📊 成績管理＋グラフ／🎯 IEPテンプレート／🕐 時間割＆準備
- 📞 保護者連絡文例／📥 提出物・連絡帳／📰 学級通信・おたより
- 🧑 児童生徒管理／✅ 出席簿／🧹 係・掃除・席替え（座席表自動生成）
- 📒 クラス日誌・週案／🏫 授業参観・懇談会／🗓 面談スケジュール
- 💗 保健室・心の天気／📁 ポートフォリオ／🌱 学級の成長ストーリー
- 📈 データ分析／⚙️ 設定（PINロック・暗号化バックアップ・引き継ぎパック 等）

すべての機能の詳しい使い方は **[docs/MANUAL.md](docs/MANUAL.md)** に記載しています。

## 🚀 使い方（クイックスタート）

1. このリポジトリを `Code > Download ZIP` などでダウンロード、または `git clone` する
2. `index.html` をダブルクリックしてブラウザ（Google Chrome 推奨）で開く
3. 初回起動時に表示される「はじめの3ステップ」に沿って、担任情報・児童生徒を登録する

これだけで使い始められます。データはブラウザの`localStorage`に保存され、次回も同じブラウザ・同じPCで開けば続きから使えます。

> 💡 「🧪 資料から授業設計（AI）」機能を使う場合は、通常の `file:///` での起動だとブラウザのセキュリティ制限（CORS）でAPI通信がブロックされることがあります。その場合は VS Code の **Live Server 拡張機能**などでローカルサーバー経由で開くことをおすすめします（詳しくはマニュアル参照）。

## 🔑 APIキーに関する重要な注意事項

「🧪 資料から授業設計（AI）」機能は**任意（オプション）機能**であり、設定しなくてもその他すべての機能は問題なく使えます。この機能を使う場合のみ、以下をご理解のうえご利用ください。

- **教材のテキスト・画像・PDFが、先生ご自身のAPIキーを通じて外部のAI事業者（Anthropic社またはGoogle社）のサーバーに送信されます。**
- **児童生徒の氏名・成績・健康情報などの個人情報は、この機能の入力欄に絶対に入力しないでください。** 送信されるのはあくまで「教材・資料の内容」であるべきです。
- APIキーは**お使いのブラウザ内（localStorage）に平文で保存**されます。共用PCや、他人がアクセスできる端末では使用しないでください。
- APIキーは、それぞれの公式サイト（[console.anthropic.com](https://console.anthropic.com)／[aistudio.google.com](https://aistudio.google.com)）でご自身のアカウントを作成し、ご自身の責任で取得・管理してください。本アプリの開発者・配布者は、APIキーの発行や利用料金について一切関与しません。
- 現在のAPI利用は**基本的に有料**です（新規アカウントには少額の無料クレジット、またはGoogleの無料枠モデルが利用できる場合があります）。想定外の課金が発生しないよう、各社のダッシュボードで利用状況・上限設定をご自身でご確認ください。
- 本アプリのソースコード（`index.html`）にAPIキーは一切含まれていません。入力したキーは画面を離れてもブラウザ内に残り続けるため、**このアプリをリポジトリとして再配布・共有する際は、ご自身のAPIキーを絶対に含めない**ようにしてください（本アプリの設計上、キーはHTMLファイル自体には書き込まれず、ブラウザのlocalStorageにのみ保存されるため、通常この点は問題になりません）。

## 🔒 プライバシー・データの扱い

- 児童生徒の氏名・特記事項などの個人情報は、**このアプリの利用者のブラウザのlocalStorageにのみ**保存されます。開発者・配布者を含め、外部の誰にも自動送信されません（上記のAI連携機能を有効にした場合を除く）。
- PINロック・自動ロック・暗号化バックアップなど、共用PCでの利用を想定したセキュリティ機能を搭載しています（設定画面から利用可能）。
- 定期的なバックアップ（設定画面の「暗号化バックアップ」または「全データバックアップ」）を強く推奨します。ブラウザのデータを消去すると、バックアップがない限り復元できません。

## 🛠️ 技術情報

- 純粋な HTML / CSS（Tailwind CDN）/ JavaScript のみで構成されたシングルファイルアプリです（ビルド不要）
- データ保存：ブラウザの `localStorage`（サーバー・データベースなし）
- 任意機能「資料から授業設計（AI）」は、Anthropic API または Google Gemini API を直接ブラウザから呼び出します（[mammoth.js](https://github.com/mwilliamson/mammoth.js)・[PptxGenJS](https://gitbrent.github.io/PptxGenJS/)・[html2canvas](https://html2canvas.hertzen.com/) をCDN経由で利用）
- 対応ブラウザ：最新版の Google Chrome を推奨（その他のモダンブラウザでも概ね動作します）
